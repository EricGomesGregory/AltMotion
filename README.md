# Project: Alt Motion
This is a Unity 6.x repository for 2.5D character controllers hand coded with C# and split into various sub-projects with their own assembly definitions.


## Top Down
The TopDown sub-project is a Zelda-like 4-directional character controller with movement and attacking.
